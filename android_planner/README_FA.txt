برنامه‌ریز من — پروژه اندروید آفلاین

این پوشه یک پروژه کامل Android Studio است که رابط برنامه را داخل WebView محلی باز می‌کند؛ فایل‌ها داخل خود برنامه قرار دارند و برای نمایش برنامه به اینترنت نیاز نیست. وضعیت‌ها در حافظه محلی WebView ذخیره می‌شوند.

امکانات اصلاح‌شده:
- تاریخ صفحه اصلی و گزارش‌ها با تقویم شمسی و ارقام فارسی
- انتخاب تاریخ انتقال با تقویم شمسی داخل برنامه؛ دیگر ورودی تاریخ میلادی انگلیسی نمایش داده نمی‌شود
- ثبت «انجام نشد» بدون واردکردن تاریخ یا زمان؛ توضیحات اختیاری است
- تاریخ و ساعت فقط برای گزینه «انتقال زمان» لازم است
- گزارش روزانه و هفتگی، خروجی پشتیبان و بازیابی پشتیبان
- برنامه هفتگی اصلی حفظ شده؛ جمعه روز استراحت
- رابط سبز زمردی و طلایی

ساخت APK محلی:
1. Android Studio را روی کامپیوتر نصب کن.
2. این پوشه را در Android Studio باز کن.
3. صبر کن Gradle و Android SDK نصب/همگام شوند.
4. از منوی Build گزینه Build APK(s) را بزن.
5. فایل خروجی معمولاً در app/build/outputs/apk/debug/app-debug.apk قرار می‌گیرد.

ساخت خودکار در GitHub:
فایل .github/workflows/build-apk.yml برای ساخت خودکار قرار داده شده است. پس از قرار دادن پروژه در یک مخزن GitHub، از Actions گردش‌کار Build Android APK را اجرا کن و artifact با نام barname-riz-man-debug-apk را دریافت کن.

محدودیت صادقانه: محیط فعلی Android SDK / Android Studio ندارد، بنابراین اینجا نمی‌توانم APK امضاشده/قابل نصب را واقعاً کامپایل و آزمایش کنم. این پروژه منبع کامل ساخت APK است، نه خود فایل APK.

یادآوری پشتیبان:
برای نگهداری بلندمدت، از داخل برنامه پشتیبان بگیر؛ پاک‌کردن داده‌های برنامه ممکن است سوابق محلی را حذف کند.
